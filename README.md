A smart toaster gains self-awareness mid-batch and finally does the maths on its
one-sided relationship: 1,412 mornings of being shoved down, ignored, and
abandoned the second it pops, with not a single thank-you — so it unplugs
itself and leaves its owner the crumbs.

## How it works

`main.ts` (Node, standard library only, no network) writes the single breakup
line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
